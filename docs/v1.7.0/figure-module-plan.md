# v1.7.0 论文配图模块实施计划

目标：以统一配图入口替代原有用户工作流，兼容旧项目记录和图片。

1. 接入论文和单图任务：读取用户提供的论文、数据及学校要求，识别已有图片和材料冲突。确认：支持已有项目，冲突不擅自裁决。
2. 配图规划：按用户数量要求或适量推荐，列出位置、目的、依据、节点与连接关系、格式和可编辑程度；反馈后反复修订，用户确认前不生成。确认：修改计划后需重新确认。
3. 图形生成：研究分析图优先，包括技术路线、流程、故障树、统计图、FMEA 和风险矩阵；保证数据和逻辑正确。默认输出高清图和可编辑 PowerPoint，统计图保留数据与源文件，适合时提供矢量图。确认：形状可独立编辑，数据不得凭空编造。
4. 外部生图：项目级授权和调用次数上限，适合的概念图可自动调用，优先视觉效果；说明整图不可逐项编辑。工程原理依据资料，概念图允许明确标识的示意细节。确认：无授权或超限不发出调用。
5. 图片复核：展示生成清单及预览，逐图反馈并反复修改；默认只改指定内容，联动需用户决定。确认：修改后重新审阅，满意前不插入。
6. 交付：用户确认后插入论文，检查图题、引用和最终排版；学校规范优先。单图任务可简化流程，但关键信息不明确仍需确认。
7. 替换与验证：核对旧入口、生命周期、研究链接和交付门禁，迁移兼容旧记录；覆盖确认失效、外部调用限制、局部修改、编辑性和旧项目回归。以实际样例检查图片与文档，再自查并提交。

范围顺序：研究分析图优先，其次工程原理图，再次机械结构示意图。用户可指定个别图片生成多个方案，调用次数计入项目上限。
